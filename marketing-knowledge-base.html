行銷知識智庫
把每天測試裡的問答，累積成自己的行銷知識資產
問 AI（會先查你的智庫，再補上專業解答）
回答會標示哪些內容來自你既有的智庫，滿意的話一鍵存回智庫，智庫就越問越厚。
① 從本機其他測試工具自動抓取
掃描同一個瀏覽器裡其他工具（英文測驗、TOEIC 計畫、其他自建題庫…）存下的問答，挑要的加進智庫。已加過或略過的不會再出現。
需要與那些工具在同一個網域開啟才掃得到（例如同一個 GitHub Pages 站台，或都用本機同一個伺服器開啟）。
② 貼上／上傳今天的測試問答
支援 Q: / A:、問：/ 答：、1. 題目 … 或 JSON 陣列。貼上後按「解析」先預覽再入庫。
