# 淨養—好好生活｜2027 節氣月曆 文案

> 規劃與決策記錄在 `淨養好好生活.md`，這份只放實際文案。
> 撰寫：2026-09-09 初稿｜狀態：**待布蕾校稿**

## 撰寫規範（每篇都要守）

**四段式結構**：節氣名＋日期 → 一句節氣感受 → 五感淨養（視聽嗅味觸各一）→ 身心安頓小 tip

**語氣**：溫暖、具體、可執行。給的是邀請不是指令。

**⚠️ 合規紅線**：一律走生活儀式／自我覺察角度。
- 不得出現：治療、改善、預防、療效、養生功效類措辭
- 不寫穴位、不寫食材功效（食材只談氣味、口感、當季感）
- 五感練習寫「做什麼」與「感覺到什麼」，不寫「對身體有什麼好處」

## 1月｜大寒　1/20（週三）

> 最冷的時候，天地反而安靜下來了。

| 感官 | 練習 |
|---|---|
| 視 | 看窗上結的霧氣，用指尖畫一個記號 |
| 聽 | 聽熱水壺燒開的聲音，那是冬天最溫柔的背景音 |
| 嗅 | 煮一鍋薑湯，讓廚房的熱氣先暖了鼻子 |
| 味 | 喝一碗熱甜湯，慢慢地喝，不要趕 |
| 觸 | 把手掌貼在溫熱的馬克杯上，停留三十秒 |

**身心安頓**：最冷的時候，也是快要回暖的時候。不用急著變好。

## ✅ 合規自查

**全篇未出現**：治療、改善、預防、療效、養生功效、穴位，以及任何食材／精油的身體功效宣稱。

**食材只談感官**：薑湯談熱氣與香味、桂圓談甜香、柚子栗子談味道，皆未連結任何身體效果。

**五感練習皆為行為描述**：寫「做什麼」與「感覺到什麼」，不寫「對身體有什麼好處」。
