# 客戶：十全

## 基本資料
- **公司**：十全特好食品股份有限公司
- **品牌**：十全
- **產業**：調味品・果醋
- **月費**：20,000（三品牌十全／iOiO／一比呀呀共用同一筆月費，分攤方式待確認）
- **案件規模**：中案／資料完整度 85%／一般排程

## 品牌定位
創立 1954 年、立基新竹的 70 年老字號。核心理念「十全十美」的品質堅持，通過 Clean Label 雙潔淨標章、FSSC 22000、ISO 22000、HACCP 認證，定位為食安守門員。融合古法釀造與現代自動化科技的高 CP 值國民品牌，主力味噌、味醂、釀造醋，並以果醋飲品引領「健康新食代」。

## 目標受眾
1. **家庭料理線**：家庭為主、有料理習慣的媽媽與愛料理的人
2. **餐飲業務線**：餐飲業者、B2B 大宗採購
3. **果醋送禮線**：25-55 歲上班族、一般企業客戶、節慶送禮需求

## 內容支柱
百年工藝職人故事、食安認證與安心、料理提案食譜、果醋健康飲、節慶送禮

## 競品
日系進口味噌味醂、台灣同業調味品牌、健康醋飲品牌、節慶禮盒電商

## 文案規範（法規紅線）
- **禁用（涉療效）**：治療、治癒、改善疾病、預防疾病、抗癌、降血壓、降血糖、降膽固醇、增強免疫力、改善過敏、解毒、消炎
- **禁用（誇大）**：減肥、瘦身、塑身、燃脂、美白、抗老、回春
- **警戒詞**：幫助消化、開胃、促進新陳代謝、調整體質
- **安全替代**：天然釀造、無添加、輕負擔、料理應用、營養補給、健康好氣色、全家安心
- **口吻**：避免療效宣稱；強調天然釀造、Clean Label 認證、料理應用、送禮情境與購買 CTA

## 果醋廣告標語候選（待定）

### 命名條件（硬性）
- 禁用字：酸／吃醋／喝醋／好喝／愛／十全的
- 大人小孩都懂，6 字內，可切 4 格分鏡（每格 1-2 字）
- 產品是天然釀造，非鮮榨 → 不可用 Squeeze
- 產品不需搖晃 → 不可用 Shake

### 中文候選
1. **想喝不用等**
2. **來一瓶，就對了**
3. **一口好心情**
4. **喝了就知道**

### 業主有感的 4 句（重點）
經 22 句提案篩選，業主明確表示只有這幾句「好記、好上口」：

| 標語 | 語言 | 特點 |
|---|---|---|
| **十全果醋咕嚕咕嚕** | 中 | 狀聲詞，小孩會跟著念 |
| **Go Fruity!** | 英 | 短、有活力 |
| **果醋 Let's GO!** | 中英混 | 節奏感強 |
| **Ready, Set, Fruity!** | 英 | 借用起跑口令，適合運動場景 |

### 關鍵洞察
業主偏好**聲音／趣味導向**（好念、好玩），而非**意義導向**（講產品好處）。
後續提案應往狀聲詞、口令、節奏感方向發想，不要再往「說明產品優點」的方向走。

### 已淘汰方向與原因
| 方向 | 淘汰原因 |
|---|---|
| 含「好喝」 | 業主不要強調好喝 |
| 含「愛」 | 小孩不懂「愛」這個字 |
| 含「十全的」 | 不要強調品牌名 |
| 超過 6 字 | 太長，分鏡畫面感不好 |
| Squeeze the day | 非鮮榨果汁，用詞不符 |
| Shake. Sip. Smile. | 產品不需搖晃 |

### 9/3-9/10｜喝法圖卡 3 篇（素材已備妥，即將發布）

原本規劃為 1 支 Reels，後改為 **3 篇獨立圖文貼文**，讓滑 IG 的人一眼看圖就進入情境。
**視覺決策**：3 篇統一用圖卡模板（產品去背 + 元素圖示 + 色塊底 + 大字），與現有單品帖九宮格視覺一致。**不走生活情境攝影**——會與既有單品帖差異過大。

**#3-2**
